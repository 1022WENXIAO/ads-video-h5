## 0.2.2 授权与游客浏览（2026-10-26）

- 未登录时直接进入创作页，可浏览创作、素材、成片、我的、设置及协议，并试填文字；不会自动调用微信登录或申请录音权限。提交制作、添加素材、领取个人积分等操作由用户主动选择登录，登录页可选择「暂不登录，先浏览」。
- 首次长按「按住说」时显示独立《声纹授权协议》，说明录音（含可能识别个人的声纹特征）的目的、处理方式、临时存储和模型处理范围。拒绝后保留文字输入，不阻断其他页面。
- 同意协议本身不会开始录音，需再次按住说话，并通过通用隐私授权和微信麦克风授权。松手、取消或离开页面后，授权晚返回也不会启动录音。
- 在「我的 → 设置 → 语音授权」可查看协议、撤回授权。授权版本与同意时间仅保存在当前运行内存，退出登录或冷启动后重新询问，未写入本地长期授权记录。
- 当前语音输入实现仅用于语音转文字，不提取声纹模板作身份识别，也不使用语音指令录音进行声音克隆。服务端临时录音由现有语音识别请求在结束时清理；第三方模型服务的处理适用其隐私政策，运营方仍需核对实际服务方与微信后台隐私指引。

发布前建议真机验收：清除登录状态后冷启动浏览四个 tab；登录后长按语音，分别测试拒绝、同意后重新按住、系统麦克风拒绝、切后台、在设置撤回后再录音。此修改只生成本地开发包，不代表已上传、已获微信审核通过或已发布。

小程序展示名称暂用「AI了吗」。这是原生 WXML/WXSS/JavaScript 客户端，与国内轻剪 H5 使用同一 API 和存储。小程序使用独立微信账号，邮箱账号继续供 H5 使用；两个身份的素材、会话、任务、成片、积分和设置各自独立。

用户已明确国内、国外两站的账号、素材和积分各自独立。国外站 `video.shikanon.com` 保留原服务，不迁移；国内 H5 与小程序在阿里云 `video.tensorbytes.com` 下使用同一 API 和存储，按同一国内后端实时保存数据，按账号身份隔离。素材通过带登录会话的国内 API 下载，国内私有 OSS 不需要客户端凭证或公开访问。

当前代码包不等于已发布的微信体验版。项目已绑定「AI了吗」的 AppID `wxf5dfb5d144bcd684`，服务端域名为 `video.tensorbytes.com`。AppID 是公开标识，客户端不需要 AppSecret 或上传私钥；仍需微信开发者权限、合法域名配置、真机验收和体验版上传。

## 开发与打包

在仓库根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build:mini
```

项目已写入 AppID；如需切换账号，可以通过本机环境变量 `QINGJIAN_MINI_APPID` 传给构建命令，或修改 `project.config.json`。构建验证页面与图标完整性、JS/JSON、官方 WXML/WXSS 编译、主包大小和 HTTPS 接口。生成 `release/qingjian-wechat/` 可导入项目与 `release/qingjian-wechat-test.zip`，清单会明确标出未上传状态和源码哈希。

微信开发者工具打开 `apps/miniprogram/` 或解压后的 `qingjian-wechat/`。无需 npm 构建、WebView 或客户端密钥。保留合法域名校验，不能用关闭校验代替真机验证。

## 微信账号配置与体验版发布

1. 确认 AppID 为 `wxf5dfb5d144bcd684`，并给本机微信账号添加开发者权限。
2. 配置服务器域名：`request`、`uploadFile` 与 `downloadFile` 均为 `https://video.tensorbytes.com`，接口路径为 `/qingjian/api`。国内素材经鉴权 API 下载，不需要国外 OSS 域名。服务器必须可达并提供有效 HTTPS 证书。
3. 根据实际使用的数据处理方配置微信《用户隐私保护指引》，声明录音、选择相册/聊天文件和保存成片到相册等功能；确认主体、类目与测试成员权限。小程序会在用户点击功能时请求隐私授权，长按期间申请麦克风授权；松手后不会因为弹窗晚完成而突然开始录音。
4. 服务端配置 `QINGJIAN_WECHAT_APP_ID=wxf5dfb5d144bcd684` 和 `QINGJIAN_WECHAT_APP_SECRET`，国内部署读取 root 私有文件 `/etc/qingjian-cn/wechat.env`（0600）。AppSecret 仅在服务端交换登录凭证，不进入项目、开发包或日志。更新服务端后确认 `/qingjian/api/health` 发布号，再联调微信登录。
5. 当前 0.2.5 已上传开发版本，尚未提交审核或发布上线。将来确认需要发布时，先由测试成员扫码完成下列验收，再在微信后台管理体验版、审核和发布。体验二维码由微信产生，开发包不会伪造二维码。

发布者需在微信工具/后台完成最后一步。本项目没有自动上传脚本，也不会将微信后台登录凭证放入仓库。

## 首版功能

- 微信登录：`wx.login` 获取一次性 code，服务端通过微信 `code2Session` 验证 AppID + OpenID，自动创建独立账号；首次登录赠送 2,000 积分，重复登录沿用原账号和余额。无需邮箱或密码。
- 「我的」使用微信原生昵称输入，昵称选填；昵称不作为登录身份，也不会按同昵称合并账号。
- 原生对话输入，手机键盘换行与独立换行按钮；长按说话、松手识别、上滑取消。识别成功后才发送指令，识别失败不会向 Agent 提交空指令。
- 从相册/摄像头添加视频、图片，从微信聊天选择 MP3/WAV/OGG 音频；最多 6 个附件，单文件不超过 100 MB。
- 自动轮询任务、显示消息时间与实际工具过程、停止及重试。已经受理的服务端任务在离开页面后继续执行。
- 会话历史、素材库、作品预览、视频/图片保存到相册；受保护文件通过带本机登录会话的下载接口加载，凭证不会进入 URL 或发送到 OSS。
- 独立积分页面、每日签到奖励卡片与领取明细。进入页面/打开卡片不会领取；点击领取才获得 1,000 积分，重复操作由服务端去重。积分耗尽后阻止新任务，已受理任务继续执行。
- 模型切换仅在设置里，复用后台可用模型；作者形象沿用账号已有设置。

精细时间线编辑、作者形象上传/动画配置与管理后台仍在 H5。首版优先覆盖手机发指令到查看/保存成片的制作流程。

## 真机验收

1. 点击微信登录自动创建账号；第二次登录仍是原账号和余额。用另一个微信账号测试素材、会话、作品和积分隔离。既有 H5 邮箱账号和国外原账号均不会自动关联。
2. 微信首次登录获得 2,000 积分，重复登录不重复赠送；积分页面打开奖励卡片不增加积分，领取增加 1,000，同日重复领取不增加。
3. 输入两行文字；键盘回车和「换行」都不发送。点击发送后任务在当前微信账号下创建。
4. 首次录音弹窗后松手，不突然启动录音；再次长按录制、松手后识别再执行。上滑取消、静音、识别失败均不提交任务。识别消耗最后积分时，已受理语音指令仍能执行。
5. 上传 PNG/JPEG、MP4、MP3；服务器验证实际格式。选中素材发指令，只附加本次选择的文件。
6. 制作时切到其他页面，再返回看到进度；成片播放到结束，保存到相册后可正常打开。
7. 模型只在设置显示；制作中切换提示等待。积分为零/负数拒绝新任务，已经受理的任务继续至结束。
8. 退出并换账号，不残留旧素材附件、录音、登录凭证或旧请求结果。

Node/官方组件模拟测试与浏览器预览不能代替微信开发者工具和真机验收；发布清单必须如实记录后两项结果。
