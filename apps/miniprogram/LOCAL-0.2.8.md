## 会话切换

- 已载入的会话在点击后立即使用缓存渲染，不等激活接口返回。
- 连续选择只在后台合并同步最后一次选择，激活接口可返回小回执。
- 提交中的消息、草稿、附件、错误及联网模式按会话保存；离开窗口不取消后台任务。
- 普通聊天、深度探索、制作分开调度。同一会话的任务仍按顺序执行。
- 空白会话继续复用；待提交消息所在窗口不参与空白会话复用。
- 个人页头像边框由外层容器统一绘制，内图清除叠加的边框和内边距，居中裁剪到圆形内圈。
- 侧边栏移除重复的“会话历史”菜单入口，直接使用下方的历史列表、搜索与筛选。

## 联网搜索与深度探索

对话输入框增加“联网搜索”“深度探索”按钮，再点选中项回到自动判断。
普通搜索执行查询、读取公开原文、回答并附来源。
深度探索根据原问题和已读证据规划下一批查询，直到证据充分、用户停止、服务失败、查询重复或没有新增可读资料。
没有固定总轮数或总研究时限；单次网络请求仍有超时，积分校验和取消机制保留。模型调用继续计费。
搜索摘要不会被当作已读取正文；正文抓取保留公开地址及 SSRF 校验。
每批证据保存到后端数据目录的 `question-research/<jobId>/snapshot.json`，完整证据保留在本地，模型使用有限工作上下文。
这份快照用于排查与保留已读材料，不代表实现了跨服务重启的研究断点续跑。

### 可选开源搜索服务

1. [SearXNG](https://github.com/searxng/searxng)：独立部署的搜索服务，后端环境变量 `QINGJIAN_SEARXNG_URL=http://127.0.0.1:8080`。
   服务配置需启用 `search.formats` 中的 `json`，调用 `/search?q=...&format=json`。
   [官方 API 文档](https://github.com/searxng/searxng/blob/master/docs/dev/search_api.rst)。
2. [open-webSearch](https://github.com/Aas-ee/open-webSearch)：复用现有适配，环境变量 `QINGJIAN_OPEN_WEBSEARCH_URL=http://127.0.0.1:3210`、`QINGJIAN_OPEN_WEBSEARCH_ENGINES=bing,baidu`。
   调用已有 `/search` HTTP request API，不读取浏览器 Cookie。

两个服务都只接受本机回环根地址，均未在本轮安装或启动。SearXNG 配置后优先使用，其次 open-webSearch；不可用时保留原有官方 Ark Responses 联网能力及已配置的只读模型回退。接口或模型未配置/不可用会如实返回资料缺口，不伪造搜索成功。
开源搜索服务的许可、运维和可用性与模型调用费用分别计算；本仓库仅增加 HTTP 适配，没有复制上游服务源码。

## 拉片与归档

已从“调整素材展示”改为整理可复用原片镜头：

- 自动生成的教学分镜、HTML 分镜和教学旁白默认归入“制作归档”，不删除文件，不改现有生成流程；需要时可恢复到素材库。
- “拉片工作台”从可用影片开始，使用现有 FFmpeg 做镜头边界检测；拉片保留全部检测结果，普通上传预览继续沿用原有最多八段的轻量策略。
- 对实际镜头抽取三帧，调用配置的画面理解模型生成画面、场景、人物描述、景别、可见变化、复用建议和标签；已有原声转写时匹配完全落在镜头时间范围内的原话，不补造台词。
- 人物使用描述性或临时标签，不能当作真人身份识别；自动边界和分析结果需要复核。
- 按场景查看镜头，预览原片，编辑归档名称与标签。归档在后台实际剪出独立 MP4，保留源文件哈希和起止时间，再加入“镜头归档”，可作为普通素材选择创作。
- 同一原片、同一时间范围重复归档会复用已有片段；原片或报告版本变化时拒绝旧选择。失败和停止保留已分析镜头，重试复用已完成分析。
- 画面理解、原声转写按实际模型用量计费；从现有报告剪出镜头不新增模型请求。
- 报告和抽帧保存在后端数据目录 `film-analysis/<sourceId>/<reportId>/`；接口按登录账号隔离，删除原片时清理对应报告缓存，已经剪出的独立归档片段保留。

可选的开源升级路线（本次未安装新的 Python 服务）：

## 运行边界

### 再次进入时的恢复

- 启动先恢复上次的会话预览、素材/成片目录、账号及积分展示，再共享一次后台刷新请求；“我的”不再额外重复请求账号资料。
- 快照按正式接口地址和当前登录凭证绑定，最长保留 24 小时，限制大小并省略大型制作日志和工程数据。界面显示“上次内容，正在同步”，最新资料到达后替换。
- 头像与封面使用微信用户目录内的独立缓存，最多 40 张、16 MB，单图不超过 512 KB，最长保留 7 天；视频与音频不作此类持久缓存。缓存文件丢失、满额或写入失败时可重新下载。
- 退出、登录失效和切换账号清理对应私有缓存；旧请求不能把上一账号的数据写回。缓存仅加速展示，提交操作前仍需完成认证刷新，积分和操作权限由服务器校验。
- 首次安装、缓存过期或未保存过的数据仍需联网加载。本次未测量线上服务器或真机耗时，未改变正式接口地址、上传微信或部署服务。

### 后端能力

当前 `miniprogram/config.js` 的正式 API 地址保持原设置。新按钮由后端 `features.researchModes` 能力标识检查；连接旧后端时给出不可用提示，普通聊天保持兼容。
实际体验新增联网与探索，需要另行连接运行此分支代码的本地后端及可用的搜索/模型配置；这次没有更换服务地址或部署线上后端。
测试采用隔离临时数据与模拟接口，不使用线上账号、生产数据或付费模型。
