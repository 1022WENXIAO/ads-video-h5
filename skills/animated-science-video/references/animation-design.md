# 用可见操作解释差异

## 同屏比较的单位

每张图应能用一句话概括“这张图比旁边改变了什么”。统一输入、配色语义、时间起点与计量单位；教学时间线不代表真实速度。多种机制若可组合，不画成互相替代的唯一演化路线。年份写代表论文年份并列出处。

四图适合大一点的网络/流程/矩阵；六图适合类型对照；八图仅用于结构较简单的图，不能把六图画面整体挤成八图。

## 过程设计案例

| 图型 | 必须看到的动作 | 结果应保留什么 |
| --- | --- | --- |
| 权重剪枝 | 先沿所有连接传输 → 标红本例弱权重 → 剪刀闭合 → 线两端分离/退去 → 只走剩余连线 | 连接数逐次下降，保留连线继续传输；小权重阈值只代表本例策略 |
| 权重量化 | 选中一个小数 → 映射/取整 → 目标整数格闪光 → 位宽格收缩 | 权重个数不变；示例是每个权重16bit变4bit，不是16个权重变4个 |
| 知识蒸馏 | 教师/学生分别预测 → 比较软分布 → 回传 → 学生分布逐轮改变 | 教师保持固定，学生逐渐接近；不是把教师参数直接搬给学生 |
| 低秩分解 | 大矩阵分解 → 行列配对重建元素 → 输入先B后A计算 | W≈AB；一般有近似误差，只有构造的秩2例子可以精确复现 |
| 激活函数 | 同批多点随机并行输入 → 落到函数曲线 → 沿输出高度进入直方图 | 相同坐标与计数尺度，输出值真实分箱；负半轴适度压缩但不能截掉重要数值 |
| 掩码扩散 | 全掩码 → 多位置同时提案 → 置信位置保留 → 低置信重遮/细化 → 最终稳定 | 不同轮次的掩码数与内容确实改变；不能只循环播放一张完成图 |
| 记忆管理 | 具体消息进入窗口 → 超预算可见溢出 → 滑窗移走旧消息 → 回答丢失该事实 | 使用“我爱喝茶”等实际事实，不能一堆无含义的A/B/C；全文保留不是机器必然爆炸 |
| 分层记忆 | 当前层 / 摘要层 / 长期层具有明确空间层级与容量 → 逐层查找 → 事实召回 | 回答来自哪一层可见；不能用三个并排同形方框叫“分层” |
| 偏好优化/强化学习 | 题目 → 学习材料 → 各自不同的比较/基线 → 参数更新 → 生成倾向改变 | 区分PPO价值基线、GRPO组内比较、DPO固定参考、SimPO长度归一化；不拿倾向条作性能排名 |

这份技能的压缩示例包含这次实际使用的剪断、断线退去、稀疏传输与接收反馈代码；激活函数示例采用144个固定种子的共同输入，8秒一轮。

## 文字与循环节奏

首次观看：只出现输入与必要图例，数据抵达哪个阶段，再出现该阶段说明。结果出现后给停留时间，后续轮次保持理解所需的说明，并用新数据调整结果。逐字输出适用于CoT中间式，例如先“4”再“×”再“2”，不需要全页标题都打字。

每一类操作应有前态、过渡、后态。对单个剪断动作，先给选中反馈，再闭合剪刀，再退线，最后更新计数。不能先减计数再让观众猜发生了什么。视频末尾可短暂交叉淡化到初态，确保循环位置没有突跳。

## 不能靠脚本代替的审阅

布局边界、数值模型、逐帧解码、音轨相关性、像素变化只能证明技术性质。需实际观看剪刀是否清楚、光点是否在合理线路行进、箭头是否指向正确对象、说明是否过多。四/六图在手机整屏上是否可读，必须检查缩小后的成片。
